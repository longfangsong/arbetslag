# Backlog

不是 ADR：ADR 记**已经定下**的事，这里记**已知、有判断、但还没决定**的事。每条要有现状（代码出处）、推荐方案、验收标准，以及"不做"的边界。定了之后搬进 `docs/adr/`，这里删掉或留一行指针。

状态：`未定` → `已定（→ ADR-xxxx）` / `已做` / `搁置`

---

## 002 落盘粒度：整份快照

**状态**: 已定（→ ADR-0016）。整份写就够：写放大来自写的次数，不是粒度；history 由所有者截断后快照有上界。

## 003 持久化分档：不是所有状态都需要 ACID

**状态**: 已定（→ ADR-0016）。分档的依据是效果种类是否可重放，不是节点自述；落盘只在进来之前、交出不可重放的效果之前、闲下来之前。
