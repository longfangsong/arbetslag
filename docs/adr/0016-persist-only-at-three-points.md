# 落盘只在三个时刻：进来之前、出去之前、闲下来之前

落盘不是为了记住内部推进，而是为了在进程死掉之后，系统对外的行为还能和死之前接得上。外部世界只看得见两样东西：我们确认收到了什么（进来的），我们对外做了什么（出去的）。图内推进到哪一步、邮箱里有什么，外面一个字节都看不到。所以**只有三个时刻必须落盘**，其余的写全是性能优化，要单独说明理由才能加。

**Status**: accepted（修订 ADR-0003「存盘点」、ADR-0006「代价」、ADR-0013「一次推进一次事务」、ADR-0014「`effectId`」）

## 前提（外部事实）

1. **要扛住的死法**：进程崩溃、重新部署，以及 Workers 上**等用户输入时主动退出**。前两种偶发；第三种**每轮都发生**。
2. **崩溃后重新问一次模型可以接受**（只是钱和时间）。
3. **对外输出可以重复**（at-least-once），不可以丢。
4. **对话历史目前只是给模型的上下文**，不是产品数据：可以截断、可以摘要。
5. **工作流可能活几个月**：不能每次从头重放，必须有检查点。

## 决定

### 三个落盘时刻

- **W1 进来之前**：向来源确认（回 200、推进 offset、`submit` / `resume` 返回）之前，这条输入必须已经落盘。路由的输入落在**发件箱**（ADR-0015），直接投递与 `resume` 落在快照的检查点里。
- **W3 出去之前**：交出一个**不可重放**的效果之前，快照必须已经落盘。它带着决定这次输出的所有非确定结果（模型说了什么）。否则崩溃后重放会得到另一个回答 B，而用户已经看到了 A：这不是"重复"，是**发散**。
- **W2 闲下来之前**：工作流停在一个点上（静止、停住、撞上轮数上限），并且没有**可重放**的效果还在执行，就落盘。这是 Workers 每轮都要走的那一步：退出必须是干净的，醒来后零重做。

除此之外**不写**：投递进邮箱、每一轮 `run`、落回执、`graph.mutate`、消费发件箱，都只改**工作副本**。

### 效果种类声明自己是否可重放

- `EffectKindDefinition` 多一个可选字段 `replayable`，默认 `false`。
- **可重放**的意思是：崩溃后忘了"它被交出过"也没关系。重放时会以同一个 `effectId` 再交一次，外部看不见差别，只是多花一次钱或时间。
  - `model.complete`：可重放。
  - 其余默认不可重放：发消息、`log.line`、`timer.wait`、`workflow.spawn`。宁可多写一次，也不要默默丢掉一个对外动作。
  - `graph.mutate` 在推进里就地执行，不交出，这个字段对它没有意义。
- 规则只有一句：**这批要交出的效果里只要有一条不可重放，就先写再交。**

### `effectId` 由快照决定

- `effectId` = `<被处理那条消息的 seq>.<它在本次转移 effects 里的下标>`。一条 `seq` 只会被消费一次，所以它在一份工作流内唯一。
- 从检查点重放时，同一条消息产生的同一个效果拿到**同一个** `effectId`。在乎重复的 Performer 用 `(workflowId, effectId)` 作外部幂等键，就能把"换激活"和"崩溃重放"两类重复一起兜住。
- 随机 id 不行：重放会产生一个新 id，外部没法认出它们是同一件事。

### 工作副本与检查点（宿主）

- **工作副本**：激活在内存里持有的那份快照，加上还没落盘的发件箱游标。只有**脏**的工作流才有工作副本。
- **检查点**：把工作副本写进存储，**一次事务**写完快照、发件箱游标，以及（形状里的触发器变了时）路由索引，然后丢掉工作副本。下次再用就从存储重新读。
  - 干净的工作流不占内存：几个月不说话的工作流不会常驻。
  - 路由索引只在触发器真的变了的那次检查点里改，不再每次推进都重写。
- 内核不知道这些。宿主给内核的 `SnapshotStore` 就是工作副本：`commit` 改内存，检查点才碰真正的存储。内核的契约（ADR-0013 的四个方法、`change` 同步且纯）一个字不改。
- **崩溃 = 退回上一个检查点**。之后发件箱里游标后面的行会再投一次，留在 `inFlight` 里的效果再交一次，可重放的效果在重放时以同样的 `effectId` 再交。

## 为什么

- **为什么不是"每步都写"**：每步都写，是把"不丢内部推进"当成了正确性。其实丢掉一段没出图的推进，外部什么都看不到，重做一遍就是了（ADR-0003 自己的论证）。我们之前多付的那些写，买到的只是"崩溃后少算一点"，而这一点在 Workers 上不值钱：闲置退出前本来就要写一次 W2。
- **为什么模型调用不用先写**：它的执行和进程同生共死（一条 HTTP 连接）。进程死了它也就没了，重启后重放会再问一次，而这是可以接受的（前提 2）。要先落盘的是模型的**结果**，而且只在它要变成对外输出的时候（W3）。
- **为什么要 W3，而不是只靠"可以重复"**：重复是同一个输出出现两次，用户能理解；发散是用户看到 A、系统记得 B，下一轮的对话就建立在用户从没见过的话上。每轮多写一次，换掉一类用户无法理解的错误。
- **为什么 W2 的条件是"没有可重放的效果在执行"**：可重放的效果（模型）很快就会回来并引出下一次写，现在写是白写。不可重放的效果（发消息、计时器）在交出前已经写过了，所以等它们的时候工作副本可以先落下来，不必等它们回来。
- **为什么 `drain` 不写**：发件箱里的行已经是持久的（W1）。游标跟着下一个检查点走，崩溃了就从旧游标再消费一次，这正是"退回上一个检查点"。
- **为什么整份写就够，不用分节点、不用追加日志**：一轮只写 2 到 3 次；history 只是上下文（前提 4），可以由它的所有者截断或摘要，所以快照有上界。粒度的问题来自"每步都写 + history 无界"，两样都去掉了，它也就不在了。

## 代价（接受）

- **崩溃会退回上一个检查点**：模型可能被重新问一次，对外输出可能重复一次（前提 2、3）。
- **转移日志会比落盘的真相走得远**：日志在每次推进后就写，崩溃后被退回的那段推进在日志里留了记录，重放时还会再记一遍。日志本来就是旁路、尽力而为（ADR-0003）。
- **内核测试与宿主测试看到的快照可能不一样**：宿主推进到一半时，存储里是上一个检查点，最新的那份在工作副本里。要看最新的就问激活（`host.snapshot(id)`）。
- **两个激活同时在线会互相覆盖**：检查点是整份覆盖写，不再靠每步的事务挡住。这本来就是 ADR-0014 禁止的；现在违反它的后果从"效果重复"变成了"进度丢失"。
- **history 必须有上界**：conversation 现在只会追加，几个月下来检查点会无界增长。在它学会截断或摘要之前，撞上快照上限就停住（ADR-0008），它会被看见，不会被悄悄吞掉。

## Retired designs（不要重提）

- **每次推进一次存储事务**（每轮 `run`、每条回执、每次 `drain` 各写一次整份快照）。
- **每次推进之后对账、重写路由索引**：只在触发器变了的那个检查点里写。
- **在飞记录必须先落盘才能交出**，不分种类：只有不可重放的种类需要。
- **随机的 `effectId`**（`crypto.randomUUID()`）：重放认不出同一个效果。
- **把对话历史拆成独立的追加日志、分节点落盘**，用来解决写放大：写放大来自写的**次数**，不是**粒度**。
- **由节点自述"我的状态可以重建"**：可不可以重放是**效果种类**的性质，由声明它的那个包回答，不由每个节点回答。

## 反转条件

- **history 变成产品数据**（用户要翻、要导出、要审计）：它要从节点状态里拿出来，变成一份只追加的记录，按记录来设计。这个 ADR 关于"整份写就够"的结论会失效。
- **重新问模型变得不可接受**（太贵，或者结果必须可复现）：`model.complete` 改成不可重放，或者在结果回来时就写一次。
- **某种输出既不能重复也不能丢**（转账）：它的 Performer 必须走外部幂等接口（`workflowId` + `effectId`），或者交出前、交出后都写，必要时人工对账。这只是一个效果种类的事，不影响三个时刻。
- **崩溃变得频繁**（不稳定的运行环境）：把 W2 的条件放宽成"静止就写"，拿写换重做。

## 验收

1. **一轮无工具对话的写次数**：路由进来一条消息，模型回答，发出回复，然后静止。存储里只有三次写：发件箱一行（W1）、发出回复之前一次检查点（W3）、静止之后一次检查点（W2）。`drain`、模型调用、模型回执都不写。
2. **可重放的效果不先写**：只交出 `model.complete` 的那次推进，存储里的快照不变。
3. **不可重放的效果先写**：交出一个默认种类的效果之后，存储里的 `inFlight` 已经有它。
4. **`effectId` 可复现**：同一份快照、同一条消息，两次 `run` 得到同样的 `effectId`。
5. **崩溃退回检查点**：工作副本没落盘时换一个激活，发件箱里的行被再投一次，结果和没崩溃时一样。
6. **路由索引只在触发器变时写**：普通推进之后，路由索引没有被重写过。
