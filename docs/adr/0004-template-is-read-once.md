# 模板只被读一次

模板只用于实例化。实例化之后，工作流的形状和状态与模板无关；改模板只影响今后新建的工作流。

**Status**: accepted

## 为什么

形状是状态（ADR-0002）。实例化之后每份工作流都会各自 spawn / connect / retire，长出不同形状；"模板持续有权威"要求框架在运行中的图上做自动改写，那是一次显式迁移，不该藏在"改文件"里。

## 代价

想让已有工作流跟上模板的变化，只能走显式迁移操作（未设计）。在此之前，唯一的办法是新建一份工作流。

## Retired designs（不要重提）

- **改模板 → 已存在的工作流自动跟着变**：需要自动改写运行中的图，且与 spawn 出来的形状冲突。
- **模板里写按会话切分的规则**：切分粒度由实例化方决定，模板不表态（ADR-0001）。
